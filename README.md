# Airline Management System

A full-stack airline management and booking system developed using Java Spring Boot and React. The application supports flight search, seat booking, payments, authentication, and admin functionality.

## Tech Stack

- Backend: Java, Spring Boot, Spring Data JPA, Spring Security
- Frontend: React
- Database: MySQL
- API: REST
- Security: JWT

## Features

- User registration and login
- Flight search and management
- Seat booking
- Payment handling
- Admin operations
- Secure REST APIs
